# AI 全玩法熟练度提升 · 2026-09-08

## “和玩家差不多”的验收标准

以熟练玩家会使用的操作作为目标：稳定完成各类赛道、通过真实漂移集气、收漂收取氮气、回正小喷、喷射中集气、根据交通情况超车，以及主动拾取并判断道具攻防时机。难度维持 Rookie / Advanced / Expert 三档，三档均会使用上述基本技术，速度选择和过弯激进程度不同。

本次没有真人圈速或胜率样本。因此结果表示达到这些技术行为指标，并显著强于紧邻上一版本的 AI；不能据此认定与某一位玩家或真人平均水平完全相同。

适用于自定义竞速、道具赛及含 AI 的职业闯关。计时赛与自由练习维持原有无对手规则。比赛中使用普通 Input 和相同的 stepCar / separateCars / stepItems；车辆参数、碰撞扣气规则、道具效果和玩家存档不因本次 AI 调整而改变。

## 实现

- `shared/ai.ts`：三档共享完整驾驶能力，移除简单档不会漂移的旧分支。漂移转向按弯道曲率与速度补偿侧滑，支持喷射期间继续集气；满气收漂、回正小喷、氮气接续仍通过合法按键触发。
- 预判冰面降低入弯目标速度，选择加速带位置并匹配其实际速度上限，绕开沙带。障碍旁保留弯道预瞄，仅在紧贴障碍时缩短目标距离，减少过早回正。
- 超车选线同时评估前车与并排行驶车辆；根据实际计划车道决定是否允许漂移和喷射，改善跟车时长期放弃集气的问题。
- `shared/ai-course.ts`：识别本圈仍可拾取的道具箱，空格时主动靠近；保留近处所有有效陷阱，综合车辆、障碍和多个陷阱选择避让方向。无足够安全空间时减速。
- `shared/ai-items.ts`：飞弹评估引擎实际锁定的前车与保护时间；护盾考虑来袭时间和陷阱布防；陷阱判断物理位置上的近追兵；道具加速避免覆盖尚未结束的氮气。
- 相同输入状态下决策可重复；不改写车辆或道具世界。静态障碍投影仅作缓存。

## 最终完整赛事对照

六个职业关卡各跑三个种子，新版 **18 场、108/108 辆车完赛**。相对上版，各组中位完赛用时缩短 **3.36%–6.96%**；碰撞合计 **1593 → 1042**，真实氮气使用 **222 → 735**，道具使用 **593 → 735**。竞速赛的三个种子结果相同，因为未启用道具随机性；它们不应视作独立随机样本。

新版车阵共有 **6 次复位**（太空道具赛 1 次、矿山道具赛 5 次），发生在 108 个参赛车辆样本中；全员最终完赛。受道具、碰撞和拥挤路线影响，不能把单车零复位结果推广到所有多人车阵。

四新版对四上版的同场混合比赛中，**12/12 场冠军由新版获得，96/96 辆车完赛**。六关卡各两个种子，并交换奇偶发车位置。这个有限机器人对照验证了实际竞争优势，不能换算为与真人比赛的胜率。

## 复现与验证

```powershell
npx tsx scripts/measure-ai-mastery.ts --all
npx tsx scripts/compare-ai-mastery.ts
npx tsx scripts/duel-ai-mastery.ts
npm test
npm run build
```

- `compare-ai-mastery.ts`：六个含对手的职业关卡 × 三个种子，每组分别跑完整旧版与新版车阵，难度和物理一致，记录完赛、碰撞、复位、资源与道具次数。
- `duel-ai-mastery.ts`：四辆新版与四辆上版同场竞技，六关卡 × 两个种子，两轮交换奇偶发车位置。是机器人对照数据，不是真人胜率。
- 新增回归覆盖所有难度真实集气、小喷、所有专家赛道喷射集气、相对本次基线的速度和碰撞总量，以及道具箱可用性、陷阱组合避让。独立审查发现“近处旁道陷阱遮蔽远处正前方陷阱”后，先复现失败再修复；只读复核通过。
- 最终全套 **200/200** 测试通过，TypeScript 与 Vite 生产构建通过。仍有既存的大 bundle 提示。
- 浏览器在英文界面完成八车 Expert 矿山道具赛启动和运行检查；比赛 HUD 正常，AI 正常离开发车区。此检查不作为持续帧率或真人驾驶难度的测量。

最终车阵数据与混合赛事结果在 `output/ai-mastery-fields-final.json`、`output/ai-mastery-duels-final.json`；测试与构建输出在 `output/ai-mastery-tests-final.txt`、`output/ai-mastery-build-final.txt`。
