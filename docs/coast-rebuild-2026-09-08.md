# 海岸场景重建交付记录

本次交付是已接入正式游戏的海岸场景重建版本。实际画面可在 `http://localhost:5173/output/coast-rebuild/review.html` 检查。页面使用与游戏相同的 World、资源加载和赛道数据。

## 已实现

- 三种不同轮廓的石屋及灯塔：实体窗洞、门窗凹槽、石台阶、分层瓦片、屋檐、烟囱和边缘倒角。
- 四种枝干与树冠轮廓、岩石断面、花草及灌木组合，共 11 个 GLB 原型。每个原型保留可编辑 `.blend` 文件。
- 海岸赛道上放置 8 栋房屋、1 座灯塔、214 棵树、78 组岩石、1,020 组小型花草/灌木；另有入户石路。场景实例按空间和真实材质分组，共 99 个批次。
- 村庄及背景林主要覆盖赛道进度约 0.155–0.375，约 174 米。道路周围的自然资产扩展到整圈。岩石位于草地以下的海岸断面，入户石路与实际门的位置对齐。
- 底色、切线法线、粗糙度、AO 及独立间接光贴图。建筑贴图为 1K/2K，自然资产为 512；运行时使用 RGB8 PNG，几何与贴图分辨率保留。
- 海岸护栏增加倒角和沿构件方向延伸的木纹；天空经度接缝修正，海面加入较长尺度波纹。海岸太阳投影降低角度，使用 4096 阴影图，修正近景墙面自阴影网纹。岩岸平台收窄，补充层理与岩石凹凸；浪花改为有柔和边缘和孔隙的透明着色，消除矩形色块。
- 首次打包将 GLB 及间接光数据从 44,570,498 字节压缩到 14,852,205 字节；补充岩石材质后最终为 15,345,416 字节。此数不包括游戏其他资源、参考图片和可编辑源文件。打包步骤验证转换前后的 RGB8 解码像素一致。

## 接入与资源管理

`client/coast-assets.ts` 读取 `public/art/coast-rebuild/manifest.json`，从 `client/coast-layout.ts` 生成确定性布局。资源全部成功后替换旧装饰层，保留与赛道一致的地面、道路和岸边层；失败时保留原装饰。

同一 World 的并发加载去重。切换赛道或加载中退出时释放迟到的模型、纹理、实例缓冲和图片数据。低质量档关闭阴影时重新编译相关材质，避免显示旧阴影图。

本次没有修改 AI、驾驶/碰撞规则、关卡目标、代币系统、语言、存档或角色/车辆模型。

## 验证

- 导出后独立验证全部 11 个 GLB 的长度、buffer-view 对齐与范围、有限顶点数据、双 UV、PBR 材质链接、PNG 位深和源文件。
- 构建：`npm run build` 通过。
- 相关场景、路面、道路边界、资源生命周期共 45 项检查通过；随后新增质量切换检查，最新相关子集 22/22 通过（累计覆盖 46 个不同检查）。
- 浏览器中已检查前视、后视、房屋、窗框、树木和海岸，使用素模及直接阴影开关区分几何、材质和投影问题。
- 1080p 整圈视点巡检使用实际 World，相机沿正式 790 米赛道移动；包含三辆展示车。它不运行完整比赛 AI/网络，因此其数据只说明该预览的渲染表现。

性能实测数据见同目录的 `coast-rebuild-performance-2026-09-08.json`，保留全部四轮数据。结果差异很大：较早暖机巡检为每秒 316.6 次回调，最终复测为 21.1 次，最后两次固定约每秒 1 次。最后浏览器可见性接口均返回 false，显示面板的请求被应用排队，符合后台限频的表现。因此既不能把较早数据宣称为稳定游戏帧率，也不能把后台数据当作前台 GPU 性能。前台完整比赛的性能验收尚未完成。

## 与参考图仍有的差距

这次已将主要建筑从简化组合替换为有完整表面数据的资产，但不能称为与参考图完全相同。

- 正式赛道的弯道曲率与两张参考图片不同。比较页前视取 t=0.30，后视取 t=0.175，明确展示同一正式赛道的两个位置；没有挪动可见道路来拼合照片。
- 当前间接光烘焙属于资产局部的天空/地面反弹与遮蔽，没有完成整个村庄与地面之间的整体 GI 烘焙。
- 岩岸母体、远处海面和云层的体积层次仍比参考图简化。树冠分面、建筑布置与参考图也不是逐点一致的重建。
- 原有车辆及角色保留，因此这些元素在对照图中的差别不属于本次场景替换结果。

## 复现与后续编辑

源文件：`art/coast-rebuild/*.blend`。确定性资产脚本：`scripts/scene-assets/architecture.py` 和 `nature.py`。

已配置的 Blender Python 位于 `output/blender-runtime/`，版本为 bpy 4.2.23；该目录已忽略，不随源码提交。包装/验证使用普通 Python 与 Pillow。

```powershell
python scripts/scene-assets/build_all.py --group all
python scripts/scene-assets/validate.py
npm run build
```

`build_all.py` 分资产启动 Blender 工作者、烘焙、导出，再压缩交付贴图并发布清单。 `.blend` 保存于打包之前，保留原始程序材质。日志和验证报告位于 `output/coast-rebuild/`。
