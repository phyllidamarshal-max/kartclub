# 多人联机验收记录 · 2026-09-09

## 交付范围

完成面向跨网络好友联机的可部署版本：2–8 人免费房、邀请链接/房间码加入、准备与倒计时、权威驾驶/道具同步、10 秒断线恢复、独立编号的共同下一场房间，以及同域部署和 Netlify 分离部署配置。没有开通付费托管、部署公网地址或修改防火墙。

## 实测

- 最终全量 `npm test`：**711 项通过，0 项失败**。运行日志：`output/multiplayer-tests-20260909.log`。
- `tests/multiplayer-*.test.ts`：服务地址与安全协议校验、邀请链接解析、身份按服务隔离、初始化去重、静态站点 HTML 回退提示、取消加入、取消再来一局、免费 10 分钟等待、门票 30 秒等待、版本拒绝、掉线撤销准备。
- 真实生产服务集成：9 个独立身份，8 人进入同一房间，第 9 人被拒绝；倒计时中离开导致取消，7 名玩家同时选择下一场仍只得到一个共同房间；驾驶输入得到服务端位移与序号确认；掉线后恢复同一身份；免费余额保持不变。
- 过期下一场：真实等待门票房超过 30 秒，晚到好友收到房间结束提示，同时保留原房间。此回归测试修复前失败、修复后通过。
- `npm run smoke`：两名车手合法完赛，模拟奖金结算、领取与奖池余额通过。
- `npm run validate:network`：4 人分别在 0 / 80 / 150ms 模拟 RTT 下完成比赛；150ms 场景加入 2% 应用消息丢失；8 人场在 150ms / 2% 下执行 5 秒断线恢复，所有车手合法完赛、结果及最终驾驶资源一致。另通过 10 次房间循环和免费余额不变检查。详细结构化记录位于 `artifacts/network-validation.json`。
- 真实 Vite 验证：账户 API、匹配和 `/socket` WebSocket 均通过同一个临时网页端口，成功收到玩家快照。脚本位于 `output/multiplayer-20260909/verify-dev.ts`，需要先启动独立测试服务 2599。
- 浏览器检查：生产入口可载入游戏；邀请链接直接进入多人页并预填房间码；实际创建房间、另一个独立标签页通过邀请加入、双人名单及准备状态更新、关闭房间返回大厅。界面截图检查后调整了浅色背景下状态和计时文字的对比度。
- `npm run build`：TypeScript 和 Vite 构建通过。保留现有的大资源包提示，未在本次联机工作中重构美术资源。

## 审查

独立只读审查发现两个问题，均已添加回归验证并修复：异步离房期间的显式退出会取消下一场连接；返回下一场地址前检查其权威比赛阶段，避免向晚到好友提供已取消的房间。

## 验证边界

网络延迟/丢包由应用消息层模拟，不能代替实际公网和跨设备测试。Docker 引擎当前未启动，因此没有执行镜像构建；已实际运行对应的 Node 生产入口、HTTP API 和 WebSocket。部署后仍需完成 [部署说明](multiplayer-deployment.md) 中的不同网络设备验收。
