# PONS Kart 0.2 验证记录

日期：2026-09-07。本次按用户追加要求重点增加 AI、关卡难度与路线差异。

## 实际交付

- 三个主题、九条不同控制点生成的独立路线。海岸港口、连续 S 弯、工业折返、午夜高架、山地九曲与巅峰试炼各有不同路线；道路宽度为 11–18 米。
- 单人竞速/道具可选 3、5、7 名 AI；新手/进阶/专家三档。AI 用与玩家相同的输入与物理，感知前车、调整超车侧、入弯减速、专家漂移与集气加速。
- 九关不同路线与目标，包含名次、漂移集气、道具使用次数、限时及四圈耐力关。自由比赛可提前练习全部路线。
- 四种模式：竞速、道具、计时最佳影子、自由练习。真实联机为 2–4 人，支持选地图、模式与圈数，AI 不参加代币比赛。
- 车车接触、擦墙滑动、正撞减速、障碍扫掠检测与重置保护；道路、小地图和近道共用几何。切换场景释放实例缓冲、阴影目标和异步模型资源。
- 经典成绩保留独立入口；模拟账本与数据不迁移、不清空。

## 浏览器与性能
