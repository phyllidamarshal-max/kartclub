# KART CLUB UI、模型与起步稳定性验证

验证日期：2026-09-08。工作区：现有 `codex/pons-kart`，本地预览 `http://localhost:5173/`。

## 本轮交付

- 大厅、九关生涯、赛道选择、联机房间、奖励页、设置、比赛 HUD 与成绩页共用深青色和青柠绿色视觉。
- 海岸、城市、山地使用实际可驾驶 Three.js 场景；赛道缩略图由同一个场景渲染器生成。
- `client/kart-model.ts` 重建车鼻、前后保险杠、黑色底部胶条、四轮、座椅、发动机、方向盘、奶油色服装手套、全盔和黑色面罩；`World.kart()` 已实际使用。保留外部角色/场景模型替换入口。
- 取消起步时持续的正弦车身上下抖动；60 Hz 物理状态与显示帧之间插值，赛车和跟随镜头使用同一姿态。复位/远距离跳变直接吸附，避免穿场滑动。
- 六语言切换及持久化；阿拉伯语 RTL。昵称、房间码、账户标识和游戏控制方向保持原含义。输入提示和可访问性属性可翻译，玩家输入值保持原样。

## 连续比赛资源

浏览器执行十局加速模拟完整八车比赛，每局均 8 人完赛。十局计数一致：8 个车模、691 个几何体、14 个纹理、11 个 shader program、517 个场景子节点。`stableResourceCounts: true`。

这是同场景连续比赛资源数量检查，不等同于完整浏览器堆快照或所有设备的长时间内存保证。

## 性能样本与边界

本机先前有效样本（2026-09-08T02:26:57.981Z）：八车、流畅档、1920×1080 渲染缓冲，四场景 P95 帧间隔为海岸 3.2 ms、城市 3.2 ms、山地 6.3 ms、山巅 6.3 ms。采样没有后台限速标记。这次有效样本早于最后的车轮宽度、头盔比例和村庄位置小修，不作为最终版本精确性能声明。

最终重采样遇到浏览器后台限速（约 1000 ms 帧间隔，`valid: false`），已排除。最终版本帧率需要在持续前台显示的游戏标签中重测；不得把无效采样或先前峰值换算成面向所有设备的帧率承诺。

## 视觉真实性说明

车手和赛车已从参考图重建并接入实时游戏，但仍不是参考图的像素级复刻。面罩反射、轮胎截面、服装褶皱及场景房屋/植被的细节与宣传图有差异。参考图未展示的背面和结构采用重建推断。功能验证通过不代表“一模一样”的视觉要求已达成；详细差异记录在根目录 `design-qa.md`。

补充：最后一次大厅交互复查修复了关闭赛事设置后旧赛道名称未更新的问题。现在关闭弹窗会重绘大厅并保留已输入昵称/房间码。浏览器已验证山地→海岸两次切换后主卡片立即同步。
