# PONS Kart 0.2 — 已批准设计

用户已确认：性能与碰撞 → 多赛道与 AI → 多模式与生涯 → UI 整合和验证。沿用现有模拟经济，不接入真实资金。

- 街机碰撞：适度侧挤/追尾，擦墙保留切向速度，正撞明显减速；重叠恢复、速度有界，重置后 2 秒透明碰撞保护。服务端执行多人碰撞。
- 三条独立赛道：海岸、城市连续弯、山地坡道及风险近道。常规 3 圈比赛约 2–4 分钟，根据实际合法输入测量调校。
- 四种玩法入口：竞速、四类道具赛（加速、护盾、追踪攻击、地面陷阱）、计时最佳影子、九关星级解锁生涯。
- 单人 AI 三难度，以路线、反应与失误区分；真实多人 2–4 人，可选赛道和竞速/道具。AI 不参与代币比赛。
- UI：赛道/模式/难度选择、房间规则、HUD 道具与状态、排名、星级与解锁、可缩放布局。Space 默认使用道具，可改键。
- 性能：批处理静态场景、减少每帧分配/DOM重建，实测帧率/帧耗时，当前设备 1080p 流畅档接近 60 FPS 为目标，不用构建成功替代性能证据。

技术约定：赛道不可变对象显式传入模拟，不能使用进程全局切换赛道；旧默认海岸 API 保留以回归旧测试。客户端预测共享车辆规则，道具及多人碰撞以服务器快照为准。轨道、高度、近道、障碍、检查点、小地图和渲染使用同一份定义。
