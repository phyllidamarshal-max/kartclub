# HUD 视觉冲击感实施计划

用户已授权「全部完成」。依据 `docs/superpowers/specs/2026-09-09-hud-vfx-impact-design.md` 连续实施全部条目。使用 subagent-driven-development / requesting-code-review；共享工作区保留其他任务改动，不提交或回滚他人文件。

## 全局约束

- 范围仅特效与必要显示接入；沿用现有 HUD 位置、驾驶/道具/名次判定、音频。显示值即时更新。
- 同一时刻最多一个主要 HUD 爆发。危险/受击/挡击优先于资源庆祝；过时提示丢弃，不排队补播。
- high/low 粒子总上限 768/192，辅助实例 64/32。低档减装饰，motion=0 保留静态信息；暂停冻结，长帧/新赛局/退出重建或清理。
- 不增加全屏后处理、相机震动、外部依赖、动态灯。动画使用真实经过时间；首次/重复/缺失快照不伪造成功。

## 工作包

- [x] HUD：资源传输、加速启动与持续、小喷双弧、碰撞残留条、定向威胁、盾形/命中形标记、事件仲裁、目标/换圈/PB；独立验收及回归。
- [x] 起跑与结算：侧翼刻度、厚字与残影、GO 峰值；金银铜主体与短入场/余辉，星级/PB错峰；独立验收及回归。
- [x] 世界效果：点火包络/接续、强弱碰撞、盾面波、环境与远车让位；保持已有池和正确挂点；独立验收及回归。
- [x] 合并预览：真实 HUD + 八车、前后对照、组合事件、全部19图渲染扫描、窄屏、低动态；记录实际画面。
- [x] 实测与收尾：65项最终特效回归和构建通过；全量789项中788项通过，唯一重连计时失败独立复跑通过；完成1080p前台CPU/GPU配对、十次资源循环、独立审查修复。性能结果有长帧，未标记为稳定60fps。
