# 第一批可玩特效实施计划

> 依据：docs/vfx-audit-and-optimization-2026-09-08.md；用户已授权「开始推进」。范围只含特效及必要显示接入，不修改玩法、名次、奖励、车辆或赛道资产。

## 架构

在 client/vfx 中隔离驾驶特效与结算特效。驾驶粒子使用固定容量池、共享 GPU 资源和有限寿命；挂点按当前车辆的后轮及排气管局部坐标转换。world.ts 只负责在车辆姿态更新后调用。结算依据最终成绩，挂载到现有结果框，交互保持可用。主程序只提供比赛身份、最终结果、暂停及权威状态。
