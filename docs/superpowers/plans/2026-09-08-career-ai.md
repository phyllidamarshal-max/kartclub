# Career AI difficulty implementation plan

> Use subagent-driven-development for independent item tactics, with root implementing driving and integration.

**Goal:** Substantially raise actual career AI pace and race pressure across all nine routes, using legal player inputs and the same physics.

**Architecture:** Replace conservative single-point AI speed/steering with advance corner-speed planning, tracked racing lines, drift recovery and legal nitro management. Add an optional item-world argument so tactical item use can inspect existing public race state. Preserve free practice, player physics, existing progression access, networking and UI translations.

**Tech Stack:** Existing TypeScript, shared fixed 60 Hz simulation and node:test. No added dependency.
