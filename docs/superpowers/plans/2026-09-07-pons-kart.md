# PONS Kart Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the independent ledger task and review; execute tightly coupled game integration locally. Steps use checkbox syntax for tracking.

**Goal:** Deliver the approved playable browser racing prototype with solo challenges, actual multiplayer and persistent simulated economics.

**Architecture:** Shared fixed-step driving and track geometry run on the client and authoritative server. Three.js renders original procedural assets. Colyseus rooms synchronize snapshots; SQLite stores atomic simulated accounting independently of live room memory.

**Tech Stack:** Node 24, TypeScript, Vite, Three.js, Colyseus, node:sqlite, Node test runner.

## Global Constraints

- 桌面浏览器优先，键盘操作，中文界面。
- 真实 2–4 人联机。
- 所有金额使用代币最小单位的整数；显示时再转换小数。
- 模拟代币门票、模拟税收注入、奖励额度预留、赛后领取和异常退款，页面持续标明模拟状态。
- 第一阶段使用原创可替换角色、赛道与原创程序化电子配乐。
- No mainnet funds, wallet secrets, deployment or external accounts required.

Protocol: client sends `input`, `ready`; server broadcasts `snapshot` containing phase, cars, players, roomId, clock, results. Input is numeric throttle/steer and boolean drift/boost/reset; no client position or result accepted.
