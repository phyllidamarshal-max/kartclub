# 集成复核修复报告

日期：2026-09-07。范围：`INTEGRATION_REVIEW.md` 的 IR01–07，以及八席房间与免费赛说明。共享驾驶修复已独立提交 `16345a3`；本轮未修改驾驶底层、经济账本、版本存储和 `output/`。

## 修改与兼容决策

- **IR01**：`pickedLaps[band]` 作为单调最高已领圈号，只有当前圈严格大于账本圈号才允许领取。圈0领取、圈1再领、逆行回圈0不能再领；保持单道具槽、满位不覆盖、正向合法进度及复位/幽灵资格要求。没有增加道具或模式。
- **IR02**：统一命中资格排除完赛、复位等待、幽灵和受击保护中的赛车；飞弹发射锁定及已有弹的目标检查同步排除复位/幽灵。一次有效攻击触发1.5秒减速，受击保护共2.5秒，即减速结束后再保护1秒。保护中的后续命中不乘速、不续期、不刷命中计数。护盾先挡一次并消耗，给予0.35秒短保护吸收同批飞弹/陷阱；该短保护会到期。
- 减速仍使用原0.45倍率，新增12世界单位/秒下限（约普通43速度上限的28%），但绝不把本来更慢的车加速到12。对车速和真实速度向量使用同一比例；原减速期20速度上限也同步约束速度向量。参数集中在冻结的 `HIT_EFFECT`；12为防连续压停的原型下限，未宣称真人平衡验证。`ItemState` 新增序列化字段 `hitProtection`，`createItems` 每局归零；现有快照携带完整ItemWorld，无新Car字段或协议消息。
- **IR03**：`classify(cars, progressAt)` 可接收权威到达时刻。服务端传入Seat的 `progressAt`，单机维护同类每车映射。当前合法进度有任何改变（含逆行、复位落点）时更新到达时刻；停在当前进度时保留它。这样“回退后重新到达”按最新到达时刻比较，不继承曾在更前方的旧时间。DNF排序不赋予完赛名次或奖金。
- **IR04**：显式Settings类型包含motion，input处理同步更新保存值和当前 `world.motion`，无需重新建图。
- **IR05**：共享 `raceDeadline` 用最早不可变完赛时刻+20秒和300秒上限取较早值。服务端在一批物理步处理完后锁定首次截止，避免同tick座位遍历顺序决定首完时刻。单机race/items使用同一规则，物理和道具步长裁剪到截止，截止即DNF结算。time、practice、五步教学豁免“首完20秒”，仍保留300秒上限及已有生涯limit；没有更改原生涯圈数/目标或普通比赛配置。
- **IR06**：单机结果表直接使用classify给出的rank，并列保留相同名次，DNF显示“—”。HUD完赛时使用相同分类语义，联机终局优先使用权威results的rank；未完成截止者显示“—”。
- **IR07**：移除教学99圈哨兵，正常圈数完成判断显式跳过教学。教学HUD显示“教学 N / 5 · 已完成 X 圈”，五步真实事件仍由Training判断。
- **房间**：房间槽数取服务端maxPlayers，尚无快照时按免费8/模拟奖金4预览；槽位与场景车辆颜色均按palette长度取余，后四席不会得到undefined颜色。免费赛的RACE BRIEF显示2–8人、无需扣票与无奖励；60/30/10%只在模拟奖金赛显示。模拟票价、奖池、份额与并列规则没有改变。

## 最终复核追加修复

此前IR05只补了“AI先完”的截止，仍遗留“本地先完即整场停止”的旧分支；另发现教学退出后对象残留，未限定模式的HUD可能将教学文字带入联机。此次追加修复：

- `clearSoloRun()` 统一清理教学对象、当前生涯关卡索引、内存影子及录制帧、分段、单机车辆/进度到达映射和临时完成状态；大厅、离局、联机倒计时入口和新单机都调用。退出等待网络离开期间保持暂停，避免已清单机状态后继续推进物理。生涯成绩、历史成绩、已保存影子和比赛选择不删除。教学retry先缓存原教学状态，再开始新局并重建Training，保留正确的重试入口。
- 教学圈数与objective增加 `mode === "solo"` 限定，即使未来某个入口遗漏清理，联机也不会显示教学。检查影子渲染和生涯目标时确认其原已有单机模式限定，本轮同步释放残留内存状态。
- `client/lifecycle.ts` 提供比赛实际调用的 `soloRaceComplete`：普通race/items达到截止或全车完成才结束；本地先完会显示“已完赛，等待其他车手…”，AI继续驾驶。time/practice/training仍可在本地完成时结束。最终个人“比赛用时”显示 `localCar.time`，DNF才使用截止elapsed，观战等待不计入个人成绩。
