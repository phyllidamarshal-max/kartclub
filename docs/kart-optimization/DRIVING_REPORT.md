# 共享驾驶与资源优化报告

状态：本子任务完成；主任务联机、UI、生命周期与最终产品验收由主代理继续。日期：2026-09-07。

## 修改与接口

- `shared/driving-config.ts`：递归冻结的驾驶参数快照 `driving-v2`，时间单位秒，角度弧度，速度为现有世界单位/秒。
- `shared/race.ts`：按车头与实际速度计算真实侧滑；合法向前且达速度/角度阈值才集气；入漂/漂移/恢复分离。保留原有障碍连续扫掠、法线损速、车车冲量、48轮接触修正。
- 两瓶库存与0–100待转换能量；启动消耗1瓶，空位立即接收满槽转换；按住不重复。3秒氮气、1.2速度上限、1.35加速度，尾段150ms缓存一次新按；连续氮气不叠乘。常规上限43、加速度22保留。
- 累计至少250ms有效漂移后拉正到8度以内产生500ms资格；新油门边沿启动350ms小喷，速度/加速度分别1.08/1.15。氮气优先；严重碰撞、复位、完成后的stepCar清理资格与缓存。
- 复位等待1.5秒且计时继续，等待不移动/集气/启动加速；恢复点取不超过当前位置与历史验证检查点的安全点；若仍在原发车格至起跑线之间，可回原始负进度格。倒车到格后不能回格向前获利。保留库存与能量，恢复后1秒车车保护，仍有道路碰撞。
- `shared/track.ts`：增加连续路段投影 `continuousTrack`，以lastT约束本地段，按线段投影而非离散最近采样点计算。实体物理与道路碰撞均采用连续投影。最近点API保留，返回精确线段点。
- 紧弯中心线弧长与内线路径长度不同：结合实际本步位移、道路曲率与分支规范进度换算限制进度；投影卡在折线顶点时仅保留最多3世界单位的实际移动预算，避免下一段投影解锁被误判跳跃。不再使用单步0.04圈作为实车判定；纯点序列回归用advanceProgress仍保留原API。
- 山地合法近路通过入口朝向与连接点选择，routeBranch持续锁定主路或近路，到合流点恢复主路；阻止相邻主路/近路在弯中无意抢投影。
- `shared/ai.ts`：跟随连续路线并使用瓶库存与新按氮气边沿，仍通过真实驾驶输入运行。
- 测试文件：新增driving-resources；补充lap/tracks；按等待1.5秒+保护1秒更新原instant-reset用例，保留碰撞精度要求。

对主任务承诺的Car字段均实现：storedNitro、miniTime、miniWindow、resetTime、slipAngle、driftState、nitroUses、miniUses、collisionCount、lastLapTime、sectorTimes。lastLapTime为从开赛起累计的权威圈末穿越时刻（在本物理步内插值）；sectorTimes为当前圈1/3及2/3已穿越段的累计圈内秒数，换圈清空。旧energy/boostTime/driftTotal/checkpoint/progress/lap/time/ack等继续保留，stepCar签名不变，Input必需字段不变。

快照/预测/重连还需保留内部字段：driftDuration、nitroBuffer、throttleHeld、resetProgress、spawnProgress、routeBranch（main/shortcut）、progressTravel、lastX、lastZ，以及原有boostHeld/resetHeld。它们均在spawnCar初始化、可直接JSON序列化。网络输入序号去重由主任务完成；本地Car的held负责按住去重。

## 参数调整依据

集气依照三角角度权重（10°零/30°峰/65°零）、速度权重、合法真实前进比例。实际有效速度阈值0.35×43；强角度漂移增加额外阻力。严重碰撞阈值impact 0.35。

唯一偏离规格参考数值的资源参数是energy.perSecond：30 → 300。现有经典路线出生点、速度35、40个60Hz物理步、油门1/转向1/漂移true，完整保持无撞墙，参考系数30仅获得6.084126729841495点；300获得60.84126729841495点，满足原型“一个有效弯约半瓶至一瓶”的目标。此改动不降低真实侧滑、速度和合法前进门槛。以30运行九路线专家AI三圈所得集气0.31–15.39点，说明保守AI大部分使用抓地与小角度修正，不能把AI完赛能力等同漂移资源平衡验证。真人手感与不同水平留存仍待试玩。

## 自审与限制

- 已检查拥有文件差异与类型，提交不包含root的server/client/protocol/items/rules/output更改。
- 物理仍为项目原有平面街机模型；山地高度是赛道表现数据，没有新增真实跳跃/腾空动力学。AC13覆盖连通路段隔离的合成高架测试，不宣称完成真实3D空中桥面碰撞。
- stepCar保持旧API容许0–1/30秒以兼容零步碰撞测试/旧调用；比赛调用方应始终按配置60Hz调度。本次AC02验证该固定步调度，不保证把不同dt直接传入stepCar得到相同轨迹。
- collisionCount记录具有明显法向冲击的新接触，持续压墙不逐tick刷计数；阈值是诊断原型，未声称精确对应真人感知撞击次数。
- 首次设置finished后，应再调用stepCar清理临时资格（其时间/库存冻结），或由主任务结束流程同步清理。上层比赛必须使用lastLapTime记录终点，而不是收到消息时刻。
- 本报告仅共享驾驶范围，不代表浏览器帧性能、真实互联网多端、完整教学/奖励系统已由本子任务验收；交由主任务验证。全部AI都是本地可重复模拟，不冒充真人客户端或真人试玩。
