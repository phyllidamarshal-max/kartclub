# 优化实施计划

用户规格 USER_SPEC_v1.0.md 是方向，当前已工作的原创内容与模拟经济保留。采用小步共享模块升级，避免换引擎或重写整套游戏。无需重新确认普通实现选择。

## 约束与兼容决策
- 60Hz物理/20Hz快照保持；保留九图、四模式、现有WASD/Shift/Ctrl/Space/R键位。
- 普通自定义默认三圈保留既有约定（路线约1.3–1.97km），生涯四圈保留；硬上限采用300秒、首完20秒、准备30秒、重连10秒的新规则。
- 免费联机扩至8人用于普通赛；已有模拟奖金场2–4人保留票价/预留/非并列份额。无法区分的并列合并所占名次份额后等分，零头返回奖池，不能按ID多拿。不开真钱或新币。
- 新规则版本 `pons-rules-0.3.0`，赛道版本 `routes-0.2.0`，性能 `standard-v1`，辅助 `manual-v1`。旧存储保留，当前成绩按完整版本隔离。
- AC02：同输入60Hz物理，30/60/120Hz渲染调度，位置绝对差<=1e-7m，时间<=1e-7s，圈数/资源库存/事件计数一致。先定容差再测。
- 现有地形为附着道路的2.5D模型，无空中自由飞行/桥下驾驶；验证邻近道路路段连续性，不声称已有跳台物理。
- 不触碰 output/ 用户工作，不迁移或删除现有余额数据；仅增量表/新存储键。

## 顺序与文件映射
1. M01：完成基线、审查与本计划；记录实际缺口。
2. M02–04 共享驾驶任务：shared/race.ts、track.ts、新增driving-config.ts及针对性 tests；合法进度、复位、真实侧滑集气、库存、小喷、缓存与渲染步长一致性。保留现有碰撞法线求解。独立子任务实现与复核。
3. M02/M05/M08 服务任务：server/room.ts/economy.ts、shared/protocol.ts、client/network.ts/lifecycle.ts，新增赛事规则/审计记录与网络脚本；加载准备、计时/并列/结算冻结、8人免费场、快照顺序与输入边沿、同一身份重连。主任务实现，与共享驾驶只通过约定接口集成。
4. M06：shared/ghost.ts、client/main.ts、教学/版本/分段模块、HUD与设置；库存、资格与复位显示、五步可重试教学、版本隔离、分段差值。主任务在驾驶接口定稿后完成。
5. 现有道具正确性：shared/items.ts 单车单圈单带防重复、命中资格与层级校验；不新增P2道具/团队玩法。
