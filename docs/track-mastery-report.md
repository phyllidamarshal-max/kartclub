# KART CLUB 赛道优化与验证报告

日期：2026-09-08。赛道版本 routes-0.5.0，规则版本 kart-rules-0.5.0，车辆物理仍为 driving-v3.2。

本轮修改实际项目中的九条赛道，按**默认三圈整场**约三分钟／五分钟设计。没有调整车辆物理、操作方式或镜头来凑时长。工作区其他任务正在修改场景、车辆模型、音乐及特效，这些不计为本次赛道交付。

## 实现内容

- 九条独立路线都有真实 V、S、U 技术弯。保留各自大体轮廓，在不同外侧路段增加 U 弯回转段；V 弯考验制动切入，S 弯考验拉正反打，U 弯支持持续漂移。
- 曲率突变处改为切线连续的圆弧过渡。各路线实测最小中心线半径约 22–33 米，冰川约 32.5 米；主路采样间距不超过 2 米，检查弯心与路宽组合，防止内侧路面折叠。
- 弯前保留准备宽度，弯后保持约 55 米恢复区，再平滑收窄。主路仍是约 10–24 米的变宽道路，五条近道为 7–7.5 米。障碍移到有通行空间的直路边缘，避开漂移弯心和近道接点。
- 五条近道的入口、出口与主路保持位置、高度和切线连续，沿用道路并集碰撞及出口进度重定位。近道比所绕过的主路短约 14%–23%，这不是整圈时间收益。
- 客户端和服务器共用时长规则。三圈短赛道硬截止 270 秒，长赛道 450 秒；第一名完赛后的 20 秒窗口保留。自由练习与教学不再受竞赛限时约束，原有圈数和训练完成条件保留。
- 每条赛道有五个实际弯段练习入口。弯前 75 米静止起步，练至弯后 65 米，重练清空资源。技巧关绑定实际弯段，港口分段时限及各关星级时间、截止同步重标定。
- 赛道选择显示真实长度、路宽、三圈时长档和 V/S/U 信息；训练选择显示动作提示。新增文案覆盖六种语言，默认英文。旧幽灵和旧版本成绩不参与新布局比较，原有解锁进度保留。

## 三圈标定

固定普通难度、技术型控制器、标准车辆、60 Hz、单车正常驾驶输入。未赠送氮气或改写车辆状态。这是长度标定基准，不是玩家平均成绩；走线、失误、近道与道具混战会改变用时。

## 验证证据

- **81 场三圈单车测试：** 九赛道 × 三难度 × 三风格全部完赛，碰撞 0，重置 0。测量前后源码哈希一致。[数据](../output/track-design-20260908/final-ai.json)
- **45 个训练弯段：** 全部从静止起步完成，均产生真实干净漂移，碰撞 0。V/U 弯内部有效漂移距离覆盖约 85%–95%；S 弯两个方向均有实际漂移。另有专家三圈碰撞复查，主路碰撞 0。[数据](../output/track-design-20260908/sections-final.json) · [强化断言日志](../output/track-design-20260908/drift-coverage-tests.txt)
- **45 组近道出口：** 五近道 × 距出口 45/20/4 米 × 三条横向走线，均继续至出口后 90 米，碰撞 0、重置 0。测试只在初始化时设置出口情境，之后提交普通驾驶输入；另有从真实入口选择近道并通过出口的测试。不能据此保证任意错误走线都不撞墙。
- **九关运行：** 27 次固定策略全部完赛，八个关卡至少一个策略达到通关条件，技巧关正确识别新弯段动作。矿山决赛夺冠尚未验证完成，详见限制。[数据](../output/track-design-20260908/career-final.json)
- **全量回归：400 项全部通过，0 失败。** 旧坐标空气墙复现及部分旧 AI 对比保留历史几何夹具；当前布局由新几何、驾驶、宽度、截止和 81 场测量覆盖，不能把历史夹具测试当成新布局测试。[日志](../output/track-design-20260908/regressions-final.txt)
- **构建通过：** 类型检查和生产打包完成，仍有主 JS 包超过 800 kB 的体积提示。[日志](../output/track-design-20260908/build.txt)
- **真实联机烟测：** 隔离本地服务和两个真实客户端完成森林一圈道具赛，分别 66.65、67.52 秒；另完成矿山三圈道具赛，分别 314.17、314.99 秒，均超过旧 300 秒上限。两次的排名、结算、模拟奖池和重复领取保护均通过。客户端由正常驾驶输入策略控制，不是真人试跑。[森林日志](../output/track-design-20260908/network-smoke.txt) · [五分钟档完整日志](../output/track-design-20260908/network-five-minute.txt)
- **浏览器：** 操作赛道选择、森林 U 弯训练、暂停、设置和重新练习；确认重练计时及资源归零，暂停时计时保持，继续驾驶后恢复。检查 1280×720、1440×900、1920×1080、2560×1270；所检查 HUD 没有越界或重叠，赛道弹窗滚动正常、底部操作可见。运行截图未合成游戏状态。

## 未验证完成的部分

1. **矿山专家决赛的夺冠可达性仍需真人标定。** 保留七名专家和夺冠主目标。基础三策略达到第 6–8 名；八种固定策略中最好第 2 名（307.29 秒）。另测八种优先保持走线的策略也未夺冠。不能把完赛描述为九关全部通关，也不能由固定 AI 的失败断定真人无法夺冠。[固定策略](../output/track-design-20260908/final-event-policies.json) · [走线优先策略](../output/track-design-20260908/final-event-line-first.json)
2. 没有改存档解锁关卡来制造通关截图。本轮未完成所有九关的真人键盘全程测试、实时幽灵追逐和道具混战截图；追击、分段时限、攻防与幽灵仍以现有流程和自动验证为主。
3. 路线变长增加了场景实例。沿用原画质，海岸几何预算按长度扩展并通过对应测试；未完成所有显卡的帧率验收。浏览器仍有 Three.js 软阴影类型弃用提示，所检查训练流程没有运行错误。

## 复现

在项目目录运行：

- npm.cmd run build
- npx.cmd tsx --test --test-concurrency=2 tests/*.test.ts
- npx.cmd tsx scripts/measure-gameplay-ai.ts --after --all --profiles
- npx.cmd tsx scripts/measure-track-mastery.ts
- npx.cmd tsx scripts/measure-career-events.ts --profiles --output=output/track-design-20260908/career-final.json
- npx.cmd tsx scripts/draw-track-mastery.ts

联机烟测设置 SMOKE_TRACK=mountain、SMOKE_MODE=items、SMOKE_LAPS=1 后运行 npm.cmd run smoke；完整五分钟档改为 SMOKE_TRACK=mountain-summit、SMOKE_LAPS=3。
